# Physics (`scam.physics`)

The per-timestep physics models: decomposition, pyrolysis gas, surface
energy balance, blowing, recession, Darcy/pressure-driven gas flow, element
transport, and the surface-chemistry backends (B′ table, live Cantera,
Mutation++). See the [theory manual](../theory/index.md) for the
derivations and [`08_surface_chemistry_backends.md`](../user/08_surface_chemistry_backends.md)
for the practical backend comparison.
